Attack Alert & Famine threshold Extension

Get pinged on Discord the moment an attack is detected, when it lands, and when your Famine reaches the set threshold.

⬇ Download Extension AlertBotExtension.zip · 3 files (manifest.json, content1.js, content2.js)
01

Download & unzip

Click the download button above. Once it's downloaded, right-click the .zip file and choose Extract All (Windows) or double-click it (Mac). You'll get a folder called AlertBotExtension with all 3 files inside.

02

Open your browser's extensions page

In Chrome or Edge, go to:

chrome://extensions  or  edge://extensions hover the mouse ang click Manage Extensions

03

Turn on Developer Mode

Look for the Developer mode toggle, usually in the top-right corner, and switch it On.

04

Load the extension

Click Load unpacked, then select the tribes-of-malaya-alerts folder you unzipped in Step 1.

05

Update & Reload the Extension

Whenever a new version is released, replace the old extension files with the new ones. Then return to the Extensions page and click the Reload button to apply the latest update.

06

Confirm it's running

Open Tribes of Malaya. You should see a console log confirming the alert engines are online. Attacks and Famine alerts will now automatically post to your Discord channel.

Heads up: This extension only detects when an attack is incoming, when it lands, and when your Famine reaches the configured threshold. It does not provide any other game automation or features.
